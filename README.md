<summary>English</summary>

**Signal Preserved in Deep Echo Runtime** — a public methodology for carrying
an attributed intention through contracts, execution and consistent projections.

Read [the method](METHOD.md), [notation](NOTATION.md) and compact
[machine-readable contracts](CONTRACTS.xml). English literary pseudocode leaves
implementation to you. The only executable utility validates this corpus.

| Example | What it explains |
| --- | --- |
| [InterDead](examples/interdead/README.md) | Portable core, hosts, provenance, Warden and delivery |
| [Workshops](examples/workshops/README.md) | Existing services brought into one interface |
| [InterDead Workshop](examples/workshops/examples/interdead/README.md) | Documents, typed relations, production graph and builds |
| [EMBO Workshop](examples/workshops/examples/embo/README.md) | A separate commerce workflow using synthetic data |

We derive from the pinned [Code Constitution](https://github.com/FOP-Oksana-Dubinetska/code-constitution)
with an [adopted engineering profile](governance/PROFILE.md). The separate
[Repository Licensing Policy](https://github.com/FOP-Oksana-Dubinetska/repository-licensing-policy)
informs our explicit [licensing map](LICENSE.md). The recorded engineering adoption has an explicit scope.

Run `make check` with Python 3.10+, Node 24.19+ and Make. It checks structure/references, not
product acceptance. Read [publication scope](PUBLICATION.md) before reuse.
Private product sources are not needed to understand the examples.

Consumers of the former C++ bootstrap retain immutable commit
`3c67103c1456f5b1dd5ce88204be658d0bbce3bd`; its MIT implementation remains
in Git history. This edition changes no consumer's dependency pin.

<summary>Українська</summary>

**Signal Preserved in Deep Echo Runtime** — публічна методологія збереження приписаного джерелу наміру в контрактах, виконанні та узгоджених проєкціях.

Почніть із [методу](locales/uk/METHOD.md), [нотації](locales/uk/NOTATION.md) та компактних [машиночитаних контрактів](CONTRACTS.xml). Англомовний літературний псевдокод залишає конкретну реалізацію за споживачем. Виконувані інструменти перевіряють структуру корпусу.

| Приклад | Предмет пояснення |
| --- | --- |
| [InterDead](examples/interdead/README.md) | Переносне ядро, адаптери, походження, Warden і постачання |
| [Майстерні](examples/workshops/README.md) | Поєднання наявних сервісів в одному інтерфейсі |
| [InterDead Workshop](examples/workshops/examples/interdead/README.md) | Документи, типізовані зв’язки, виробничий граф і збірки |
| [EMBO Workshop](examples/workshops/examples/embo/README.md) | Окремий комерційний процес із синтетичними даними |

Метод спирається на закріплену [Конституцію коду](https://github.com/FOP-Oksana-Dubinetska/code-constitution) та [чинний профіль](governance/PROFILE.md). [Політика ліцензування репозиторіїв](https://github.com/FOP-Oksana-Dubinetska/repository-licensing-policy) визначає основу явної [ліцензійної карти](LICENSE.md). Інженерне прийняття має власну записану область.

Перевірка: `make check` із Python 3.10+ та Node 24.19+, або `node tools/warden.mjs`. Вона охоплює перелік публічних файлів, XML, ідентифікатори, посилання та сценарії відмови. Приймання продукту й оцінка літературного змісту мають окремі докази. Перед використанням прочитайте [межу публікації](locales/uk/PUBLICATION.md).

Споживачі попередньої C++-основи зберігають незмінний коміт `3c67103c1456f5b1dd5ce88204be658d0bbce3bd`; його MIT-реалізація доступна в історії Git. Ця редакція зберігає закріплені залежності споживачів.

Метод опирается на закреплённую [Конституцию кода](https://github.com/FOP-Oksana-Dubinetska/code-constitution) и [действующий профиль](governance/PROFILE.md). Приёмка продукта и оценка литературного содержания имеют отдельные доказательства. Перед использованием прочитайте [границу публикации](locales/ru/PUBLICATION.md).

Потребители прежней C++-основы сохраняют неизменный коммит `3c67103c1456f5b1dd5ce88204be658d0bbce3bd`; его MIT-реализация доступна в истории Git. Эта редакция сохраняет закреплённые зависимости потребителей.
