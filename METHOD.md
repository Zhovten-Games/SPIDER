# Preserve the decision, project the result

Start with an attributed intention. Turn it into a contract, execute it at one
authoritative boundary, and derive the views people and tools need.

1. Attribute the source, revision, rights and editorial status.
2. Specify inputs, authority, preconditions, effects and refusal.
3. Resolve stable IDs and versions before changing live state.
4. Commit valid candidate state, events, receipt and evidence together.
5. Project only information and actions permitted for the audience.
6. Verify the real boundary with named expected and observed values.
7. Deliver the checked projection with its source identity.

An instruction can authorize an operation. An assistant's guess or a green
check cannot create authority, literary approval or a new norm. Group membership
is navigation; a semantic relation needs its own reason.

Keep this generic layer small. Projects supply vocabulary, rules, source
adapters and acceptance cases. A game, corpus or commerce system can use the
method without adopting another project's stack or domain model.
