# Локальные правила разработки

`spider-dev-0.1.0-candidate`, CC BY-SA 4.0. Источник: Конституция кода,
commit `220dc9c286ae06f8b6ed60cdda75112eed0408ed`, и её
`governance/legislation/DEVELOPMENT.md`. Область — SPIDER bootstrap.
Принятие профиля пока не заявлено. Конкретные технические правила ниже
исполняют текущий запрос и определяют контракт проверяемых артефактов.

| ID | Правило | Свидетельство |
| --- | --- | --- |
| SP-S01 | Каждый артефакт помечен source/generated/fixture/external/report. | manifest/artifacts.json |
| SP-T01 | C++20, стандартная библиотека, Make; Python для проверок. Потребитель вправе переопределить стек. | make check; project override |
| SP-A01 | Переносимый компонент не выполняет host I/O, не читает реальные часы и не знает игровой домен. | Проверка границы плюс обзор diff |
| SP-C01 | Стабильный ID команды, revision, атомарный отказ и проверяемые последствия. | Контракт потребителя и Warden |
| SP-L01 | Ключ, запрошенная/выданная локаль и fallback явны; неизвестный ключ — ошибка. | localization scenario |
| SP-N01 | Предметные имена файлов kebab-case; типы PascalCase, функции/поля snake_case, bool is_/has_. | Обзор diff; автоматическая проверка только доступных границ |
| SP-P01 | Все внешние зависимости закреплены по commit и атрибутированы. generated не редактируется вручную. | manifest/dependencies.json |
| SP-E01 | Один offline `make check`; отчёт называет область, версии и ограничения. Полное конституционное соответствие не выводится из exit 0. | Check output и human review |
| SP-O01 | Override содержит исходное правило, область, причину, замену, проверку и статус. | normative-translation.json |

Обычный цикл: задача → изменение → достаточная проверка → доступный diff →
сообщение результата → решение человека там, где оно требуется полномочием.
Уже порученная обратимая подготовка репозитория не требует повторного согласия.
Необратимая внешняя поставка и ратификация не подменяются этой подготовкой.
