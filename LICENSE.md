# Licensing

This repository applies the [Repository Licensing Policy](https://github.com/FOP-Oksana-Dubinetska/repository-licensing-policy)
through `.licensing-policy`, pinned at
`6e4c2627717c079827ed4aa9044a5346b3ea3ddb`. The submodule is incorporated
by reference; this declaration applies the following scoped map.

| Scope | License |
| --- | --- |
| New editorial prose and methodology documentation | CC-BY-SA-4.0 |
| XML pseudocode, schemas/templates, scripts and tests | MIT |
| Historical C++ bootstrap and its original MIT materials | Existing MIT terms |
| Adapted constitutional texts | CC-BY-SA-4.0 with attribution |
| Names, logos, trademarks and brand identity | No license granted; all rights reserved |
| Third-party materials and policy submodules | Original terms and notices |

Root `LICENSE` supplies MIT for the MIT scopes, not a blanket branding or upstream
policy grant. No project-specific overrides exist. Mandatory upstream terms,
file notices and subtree notices precede this default map, in that order.
Reference texts are under `.licensing-policy/LICENSES/`. A case study grants
no additional rights to the product it names. Private game/EMBO code is excluded.
